# AI-ML-Portfolio
My portfolio for Junior AI/ML Engineer roles, showcasing projects from my 6-week learning plan.

## Week 1: Pandas Housing Data Analysis
- **Folder**: `Python and Pandas`
- **Files**: `house_price_analysist.ipynb`, `top_expensive_houses.csv`, `avg_price_by_bedrooms.png`
- Analyzed a housing dataset with Pandas, filtered 3-5 bedroom houses, computed min/max/average prices, and visualized trends with Matplotlib.
- Skills: Python, Pandas, Matplotlib, Data Analysis, Data Visualization

## Week 2: NumPy Matrix Analysis
- **Folder**: `Numpy`
- **File**: `Week2_NumPy.ipynb`
- Used NumPy to create a matrix of bedrooms and prices, filtered 3-5 bedroom houses, and computed per-bedroom statistics with formatted integer output.
- Skills: Python, NumPy, Data Preprocessing

## Week 2: Machine Learning with scikit-learn
- **Folder**: `ML_basics`
- **File**: `Week2_ML_Basics.ipynb`
- Built a linear regression model to predict house prices from bedrooms, evaluated with R² score and prediction comparisons.
- Skills: Python, scikit-learn, Linear Regression, Model Evaluation
